Changelog

Todas as mudanças importantes do Browser 98 serão documentadas neste arquivo.

[1.1 Beta] - 2026

Adicionado

- Sistema de downloads.
- Sistema de favoritos.
- Suporte a entrada de usuário no protocolo Gemini.
- Suporte a redirecionamentos Gemini.
- Suporte a buscas Gopher.
- Carregamento assíncrono de imagens.
- Gerenciamento de tamanho do cache.
- Identificação de arquivos para download.
- Nova identificação de User-Agent.
- Tela "Sobre o Browser 98".
- Indicadores de status durante carregamentos e downloads.

Melhorado

- Renderização HTML.
- Renderização Gemini.
- Renderização Gopher.
- Navegação entre páginas.
- Gerenciamento do histórico.
- Interface gráfica.
- Sistema de cache.
- Compatibilidade com servidores Gemini.
- Suporte a listas e elementos de formatação HTML.

Conhecido

- O suporte a HTML ainda é limitado.
- JavaScript não é executado.
- CSS moderno não é suportado.
- A validação tradicional de certificados TLS Gemini está desativada por compatibilidade.
- O suporte a Gopher ainda está em desenvolvimento.
- A compatibilidade com sistemas operacionais muito antigos ainda não foi validada oficialmente.

[Versão pública anterior]

A versão pública anterior do Browser 98 estabeleceu a base do navegador e implementou:

- HTTP;
- HTTPS;
- HTML básico;
- Gemini;
- Gopher;
- histórico de navegação;
- cache;
- renderização de imagens.

Essa versão serviu como base para o desenvolvimento da versão 1.1 Beta.

---

[Histórico]

2021

Início do desenvolvimento do Browser 98.

O projeto passou por diferentes versões, experimentos e recriações ao longo de seu desenvolvimento.

2024

Uma versão do Browser 98 foi integrada ao projeto NewXP, um projeto desenvolvido em colaboração com um colega e baseado no Windows XP com uma interface inspirada no Windows 10.

O projeto NewXP foi posteriormente descontinuado.

2026

O desenvolvimento do Browser 98 continua como um projeto independente.

A versão 1.1 Beta representa uma nova etapa de desenvolvimento, trazendo melhorias de navegação, cache, downloads, favoritos, Gemini e Gopher.
